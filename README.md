## Projetos em destaque

### [Auto Session](https://github.com/gimorais/auto-session-php)

Mini sistema para cadastro e manutenção de marcas e modelos de veículos, utilizando sessões do PHP como armazenamento temporário.

O projeto possui:

- cadastro, edição, exclusão e pesquisa de registros;
- relacionamento entre marcas e modelos;
- validações no front-end e no back-end;
- tema claro e escuro;
- interface responsiva;
- deploy com Docker no Render.

**Tecnologias:** PHP, JavaScript, HTML, SCSS, Bootstrap e Docker.

[Ver repositório](https://github.com/gimorais/auto-session-php) · [Acessar demonstração](https://auto-session-php.onrender.com/)
